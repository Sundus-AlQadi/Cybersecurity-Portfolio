# Authentication Vulnerabilities

This folder contains selected documentation from the Authentication Vulnerabilities learning path in PortSwigger Web Security Academy.

The learning path covered authentication testing concepts and practical labs related to login security, password attacks, multi-factor authentication, password reset logic, cookie-based authentication, and account takeover scenarios.

## Topics Covered

- Username Enumeration
- Password Enumeration
- Brute Force Attacks
- Broken Brute Force Protection
- Account Lock Logic Flaws
- Two-Factor Authentication Bypass
- Two-Factor Authentication Broken Logic
- Stay-Logged-In Cookie Vulnerabilities
- Offline Password Cracking
- Password Reset Vulnerabilities
- Password Reset Poisoning
- Password Change Logic Flaws

## Tools Used

- Burp Suite Community Edition
- Burp Proxy
- Burp Repeater
- Burp Intruder
- Turbo Intruder
- Burp Decoder
- Exploit Server
- Web Browser

## Skills Practiced

- Analyzing login responses
- Identifying username and password enumeration
- Testing brute-force protections
- Manipulating HTTP requests
- Testing password reset flows
- Analyzing cookies and tokens
- Using Grep Match and Grep Extract
- Documenting findings and mitigations

## Notes

All labs were completed in controlled PortSwigger Web Security Academy environments for educational purposes.
