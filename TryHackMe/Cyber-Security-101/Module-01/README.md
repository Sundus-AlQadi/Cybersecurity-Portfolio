# Module 1: Start Your Cyber Security Journey

**Platform:** TryHackMe  
**Learning Path:** Cyber Security 101  
**Status:** Completed 

## Overview

This module introduced me to offensive and defensive security. I also learned
how to search for technical information and evaluate online sources.

## Completed Rooms

### 1. Offensive Security Intro

**Room:** [Offensive Security Intro](https://tryhackme.com/room/offensivesecurityintro)

I learned that offensive security involves finding and safely exploiting
weaknesses in systems with permission.

In the practical lab, I used a terminal to discover a hidden page in a simulated
banking website and used the exposed function to complete the task.

### 2. Defensive Security Intro

**Room:** [Defensive Security Intro](https://tryhackme.com/room/defensivesecurityintro)

I learned that defensive security focuses on preventing attacks, detecting
intrusions, and responding to security incidents.

The room introduced me to:

- Security Operations Centers (SOC)
- Security Information and Event Management (SIEM)
- Incident response

In the practical activity, I investigated alerts in a simplified SIEM simulation
and identified suspicious activity.

### 3. Search Skills

**Room:** [Search Skills](https://tryhackme.com/room/searchskills)

I learned how to search for technical and cybersecurity information more
efficiently.

I used search operators such as:

- `"exact phrase"` to search for an exact phrase
- `site:` to search within a specific website
- `-` to exclude unwanted results
- `filetype:` to search for a specific file type

I also explored resources such as:

- Shodan
- Censys
- VirusTotal

I learned to evaluate information by checking the source, supporting evidence,
objectivity, and whether other reliable sources confirm it.

## What I Learned

After completing this module, I can:

- Explain the difference between offensive and defensive security.
- Describe how SOC analysts monitor and investigate security alerts.
- Use search operators to find specific technical information.
- Use specialized cybersecurity resources for basic investigations.
