### 2. Windows Fundamentals 2

**Room:** [Windows Fundamentals 2](https://tryhackme.com/room/windowsfundamentals2x0x)

I explored Windows utilities used to view system information, monitor resources,
and manage system settings.

Tools covered:

| Tool | Purpose |
|---|---|
| `MSConfig` | View system configuration and startup settings |
| `compmgmt` | Open Computer Management |
| `msinfo32` | View system and hardware information |
| `resmon` | Monitor CPU, memory, disk, and network usage |
| `cmd` | Open Command Prompt |
| `regedit` | View the Windows Registry |

I also practiced basic Command Prompt commands such as:

- `hostname`
- `whoami`
- `ipconfig`
- `netstat`
- `net`
