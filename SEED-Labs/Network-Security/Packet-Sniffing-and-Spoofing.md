# SEED Lab: Packet Sniffing and Spoofing

## Category
Network Security

## Environment
Controlled academic lab environment using SEED Ubuntu VM.

## Objective
The goal of this lab was to understand how packets can be captured, inspected, and crafted in a controlled network environment.

## Concepts Practiced
- Packet sniffing
- Packet spoofing
- ICMP packet analysis
- Network interfaces
- Wireshark packet inspection
- Scapy basics

## Tools Used
- SEED Ubuntu VM
- Linux Terminal
- Wireshark
- Scapy
- Python

## Lab Summary
In this lab, I practiced capturing network packets and analyzing their structure. I also learned how spoofed packets can be crafted in a controlled environment to better understand how network communication works.

## What I Learned
- How packet sniffing helps analyze network traffic.
- How ICMP packets are structured.
- How spoofed packets can be created for learning purposes.
- Why packet-level visibility is important in network security.

## Security Relevance
Packet sniffing and spoofing are important concepts in network security because they help explain how attackers may observe or manipulate traffic if networks are not properly protected.

## Mitigation / Defense
- Use encrypted protocols where possible.
- Monitor abnormal packet behavior.
- Segment networks properly.
- Use intrusion detection systems.
- Avoid trusting unauthenticated network traffic.

## Note
This lab was performed only in a controlled academic environment.
